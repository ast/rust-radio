* rust-radio — SDR and Radio Control in Rust

Copyright 2025-2026 Albin Stigö SM6WJM/AD8KM

A Rust workspace for software-defined radio reception, real-time audio streaming, and amateur radio control.

** Workspace Crates

*** Signal Processing
- [[file:airspyhf-sys/README.org][airspyhf-sys]] — Raw FFI bindings to =libairspyhf= (generated with =bindgen=)
- [[file:airspyhf/README.org][airspyhf]] — Safe Rust wrapper providing callback-based IQ streaming (=Complex32=)
- [[file:signals/README.org][signals]] — Complex oscillators (standard, fast, Fs/4-optimized), file source, noise source
- [[file:filters/README.org][filters]] — FIR filters, decimation chains, and frequency shifting for =Complex32=
- [[file:doublemap/README.org][doublemap]] — Lock-free ring buffer via =memfd_create= + double memory mapping
- [[file:pool/README.org][pool]] — Pre-allocated buffer pools for real-time paths
- [[file:spectrum/README.org][spectrum]] — FFT-based spectrum analyzer (windowing + power density)
- [[file:receiver/README.org][receiver]] — Main SDR receiver binary: streams IQ from AirspyHF, serves spectrum over a Unix socket

*** Audio Streaming
- [[file:rtp/README.org][rtp]] — RTP header construction for network audio
- [[file:sideband/README.org][sideband]] — Captures audio via =cpal=, encodes with Opus, streams as RTP/UDP

*** Radio Control
- [[file:sidebridge/README.org][sidebridge]] — Async =Radio= trait hierarchy, Icom CI-V parser/codec (=nom=), and =civ-bridge=/=civ-client= binaries
- [[file:civlink/README.org][civlink]] — WebRTC-based web interface for remote Icom radio control (audio, spectrum, rig control via browser)

** Building

#+begin_src bash
  cargo build                 # build entire workspace
  cargo test                  # run all tests (hardware tests are #[ignore])
  cargo bench -p filters      # run benchmarks for a crate
#+end_src

=airspyhf-sys= requires =libairspyhf= headers and library installed on the system.

** Cross-compiling for Raspberry Pi

#+begin_src bash
  cargo install cross --git https://github.com/cross-rs/cross
  # You have to docker login to ghcr.io or it will fail
  cross build --target aarch64-unknown-linux-gnu --release
#+end_src

A =Justfile= is provided for common workflows:

#+begin_src bash
  cargo install just

  just build-pi              # cross-build sideband for Pi
  just upload                # build + scp to remote "shack"
  just deploy                # build + upload + run on Pi
#+end_src

** Dependencies

- Rust 2024 edition
- =libairspyhf= (for =airspyhf-sys=)
- =libasound2-dev= (for =cpal= audio in =sideband= and =civlink=)
- =cmake= (for building the Opus codec, needed by =sideband= and =civlink=)
- =libopus-dev= (for cross-compilation, see =Cross.toml=)
- =gstreamer= (for receiving/testing RTP audio streams, see =sideband/README.org=)
- Node.js + npm (for the =civlink= frontend, see =civlink/README.org=)
